========================================
نشر الإصلاح النهائي
========================================

تم تعديل عدد الحصص اليومية من 7 إلى 8

السعة الجديدة: 5 أيام × 8 حصص = 40 حصة

هذا سيحل المشكلة لأن البيانات تحتاج 37 حصة فقط

========================================
خطوات النشر
========================================

1. افتح Cloud Shell:
   https://console.cloud.google.com/cloudshell

2. ارفع ملف config.py المحدث:
   - افتح Cloud Shell Editor
   - اذهب إلى: backend_v2/app/config.py
   - استبدل السطر:
     periods_per_day: int = 7
   بـ:
     periods_per_day: int = 8

3. نفذ الأمر:

cd ~/backend_v2
gcloud run deploy schedule-solver --source . --region us-central1 --allow-unauthenticated --timeout 300 --memory 2Gi --cpu 2

4. انتظر حتى يكتمل النشر (2-3 دقائق)

5. جرب التطبيق:
   https://etisak-784d6.web.app

========================================
النتيجة المتوقعة
========================================

✅ سيتم قبول البيانات (37 حصة < 40 حصة)
✅ سيتم توليد الجدول بنجاح
✅ لن تظهر رسالة "تجاوز السعة"
