خطوات النشر
========================================

1. افتح Cloud Shell:
   https://console.cloud.google.com/cloudshell

2. ارفع ملف solver_service.py المحدث:
   - افتح Cloud Shell Editor
   - اذهب إلى: backend_v2/app/services/solver_service.py
   - استبدل المحتوى بالملف المحدث من مشروعك

3. نفذ الأمر:

cd ~/backend_v2
gcloud run deploy schedule-solver --source . --region us-central1 --allow-unauthenticated --timeout 300 --memory 2Gi --cpu 2

4. انتظر حتى يكتمل النشر (2-3 دقائق)
