## 🎯 نماذج البيانات (Domain Models)

### 1. PerformanceStats
```dart
class PerformanceStats {
  final double overallSuccessRate;      // نسبة النجاح الإجمالية
  final double excellenceRate;          // نسبة التميز
  final double improvementRate;         // نسبة التحسن
  final Map<String, double> performanceLevels;  // توزيع المستويات
  final Map<String, double> successRatesByClass;  // نسب النجاح حسب الفصول
  final int totalStudents;              // إجمالي الطلاب
  final int successfulStudents;         // الطلاب الناجحون
}
```

### 2. GapStats
```dart
class GapStats {
  final int totalGaps;        // إجمالي الفجوات
  final int criticalGaps;     // الفجوات الحرجة
  final int resolvedGaps;     // الفجوات المعالجة
  final List<LearningGapInfo> gaps;  // قائمة الفجوات
}
```

### 3. LearningGapInfo
```dart
class LearningGapInfo {
  final String subject;           // المادة
  final String className;         // اسم الفصل
  final String description;       // الوصف
  final int affectedStudents;     // عدد الطلاب المتأثرين
  final String priority;          // الأولوية (حرجة/متوسطة/منخفضة)
}
```

### 4. TeacherStats
```dart
class TeacherStats {
  final String teacherId;         // معرف المعلم
  final String teacherName;       // اسم المعلم
  final String teacherEmail;      // بريد المعلم
  final double avgExcellence;     // متوسط التميز
  final int currentLoad;          // الحصص الحالية
  final int maxLoad;              // الحد الأقصى للحصص
  
  double get loadPercentage => (currentLoad / maxLoad) * 100;
}
```

## 🔧 الخدمات (Services)

### 1. SuccessRatesService

#### الوظيفة الرئيسية
```dart
Future<PerformanceStats> calculatePerformanceStats(String schoolId)
```

#### الخطوات:
1. جلب جميع الطلاب من Firestore
2. حساب نسبة النجاح (>= 60)
3. حساب نسبة التميز (>= 90)
4. حساب توزيع المستويات
5. حساب نسب النجاح حسب الفصول

#### مثال الاستخدام:
```dart
final service = SuccessRatesService();
final stats = await service.calculatePerformanceStats('school123');
print('نسبة النجاح: ${stats.overallSuccessRate}%');
```

### 2. LearningGapsService

#### الوظيفة الرئيسية
```dart
Future<GapStats> calculateGapStats(String schoolId)
```

#### الخطوات:
1. جلب جميع الطلاب والفصول
2. تحليل أداء الطلاب في المواد الأساسية
3. اكتشاف الفجوات بناءً على نسبة الضعفاء
4. تصنيف الفجوات حسب الأولوية
5. ترتيب الفجوات (الحرجة أولاً)

#### معايير الأولوية:
```dart
if (weakPercentage >= 30) {
  priority = 'حرجة';
} else if (weakPercentage >= 15) {
  priority = 'متوسطة';
} else {
  priority = 'منخفضة';
}
```

### 3. TeacherPerformanceService

#### الوظيفة الرئيسية
```dart
Future<List<TeacherStats>> calculateAllTeachersStats(
  String schoolId,
  ScheduleRepository scheduleRepo,
)
```

#### الخطوات:
1. جلب جميع المعلمين
2. جلب جميع الطلاب والفصول
3. لكل معلم:
   - حساب عدد الحصص من ScheduleRepository
   - جمع طلاب المعلم من الفصول المعينة
   - حساب متوسط درجات الطلاب
4. ترتيب المعلمين حسب متوسط التميز

## 🎨 Providers (Riverpod)

### 1. Service Providers
```dart
final successRatesServiceProvider = Provider<SuccessRatesService>((ref) {
  return SuccessRatesService();
});

final learningGapsServiceProvider = Provider<LearningGapsService>((ref) {
  return LearningGapsService();
});

final teacherPerformanceServiceProvider = Provider<TeacherPerformanceService>((ref) {
  return TeacherPerformanceService();
});
```

### 2. Data Providers
```dart
final performanceStatsProvider = FutureProvider<PerformanceStats>((ref) async {
  final user = ref.watch(authStateProvider).value;
  if (user == null || user.schoolId == null) {
    return PerformanceStats.empty();
  }
  
  final service = ref.watch(successRatesServiceProvider);
  return await service.calculatePerformanceStats(user.schoolId!);
});

final gapStatsProvider = FutureProvider<GapStats>((ref) async {
  final user = ref.watch(authStateProvider).value;
  if (user == null || user.schoolId == null) {
    return GapStats.empty();
  }
  
  final service = ref.watch(learningGapsServiceProvider);
  return await service.calculateGapStats(user.schoolId!);
});

final teacherStatsProvider = FutureProvider<List<TeacherStats>>((ref) async {
  final user = ref.watch(authStateProvider).value;
  if (user == null || user.schoolId == null) {
    return [];
  }
  
  final service = ref.watch(teacherPerformanceServiceProvider);
  final scheduleRepo = ref.watch(scheduleRepositoryProvider);
  return await service.calculateAllTeachersStats(user.schoolId!, scheduleRepo);
});
```

## 📄 إنشاء PDF

### الخطوات الأساسية
```dart
Future<void> _generatePDF(BuildContext context, Data data) async {
  final pdf = pw.Document();
  
  // 1. تحميل الخطوط العربية
  final fontDataRegular = await rootBundle.load('assets/fonts/Amiri-Regular.ttf');
  final fontDataBold = await rootBundle.load('assets/fonts/Amiri-Bold.ttf');
  final arabicFontRegular = pw.Font.ttf(fontDataRegular);
  final arabicFontBold = pw.Font.ttf(fontDataBold);
  
  // 2. تحميل الشعار
  final logoData = await rootBundle.load('assets/logokshuf.webp');
  final logoImage = pw.MemoryImage(logoData.buffer.asUint8List());
  
  // 3. إضافة صفحة
  pdf.addPage(
    pw.Page(
      pageFormat: PdfPageFormat.a4,
      textDirection: pw.TextDirection.rtl,
      theme: pw.ThemeData.withFont(
        base: arabicFontRegular,
        bold: arabicFontBold,
      ),
      build: (pw.Context context) {
        return pw.Column(
          children: [
            // الكليشة الرسمية
            _buildOfficialHeader(),
            // المحتوى
            _buildContent(data),
            // التذييل
            _buildFooter(),
          ],
        );
      },
    ),
  );
  
  // 4. حفظ وعرض
  final bytes = await pdf.save();
  
  if (kIsWeb) {
    // للويب: فتح في نافذة جديدة
    final blob = html.Blob([bytes], 'application/pdf');
    final url = html.Url.createObjectUrlFromBlob(blob);
    html.window.open(url, '_blank');
    html.Url.revokeObjectUrl(url);
  } else {
    // للموبايل: استخدام Printing
    await Printing.layoutPdf(
      onLayout: (PdfPageFormat format) async => bytes,
      name: 'report.pdf',
    );
  }
}
```

### الكليشة الرسمية
```dart

    child: pw.Row(
      mainAxisAlignment: pw.MainAxisAlignment.spaceBetween,

          crossAxisAlignment: pw.CrossAxisAlignment.start,

        // اليمين: الرقم والتاريخ

          children: [
            pw.Text('الرقم: _____'),
            pw.Text('التاريخ: _____'),
          ],
        ),
      ],
    ),
  );
}
```

## 🚀 التحسينات المستقبلية

### 1. Caching
```dart
final performanceStatsProvider = FutureProvider.autoDispose<PerformanceStats>((ref) async {
  // إضافة cache
  final cache = ref.watch(cacheProvider);
  final cached = cache.get('performance_stats');
  if (cached != null) return cached;
  
  final stats = await service.calculatePerformanceStats(schoolId);
  cache.set('performance_stats', stats, duration: Duration(minutes: 5));
  return stats;
});
```

### 2. Pagination
```dart
final teacherStatsProvider = FutureProvider.family<List<TeacherStats>, int>((ref, page) async {
```
