========================================
أوامر سريعة للرفع إلى GitHub
========================================

📋 الخطوات:

1. فتح Terminal في مجلد المشروع:
   cd C:\path\to\your\flutter\project

2. التحقق من الحالة:
   git status

3. إضافة التحديثات:
   git add lib/src/features/academic/presentation/

4. كتابة رسالة التحديث:
   git commit -m "✨ إضافة أزرار الحذف والتعديل لقائمة الخطط"

5. الرفع إلى GitHub:
   git push origin main

========================================
