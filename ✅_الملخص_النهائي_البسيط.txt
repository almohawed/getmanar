الخطوة 1: مسح الـ Cache

2. افتح: https://etisak-784d6.web.app/
3. ستظهر التعديلات! ✅

الخطوة 2: إصلاح صلاحيات Firebase
----------------------------------
1. افتح: https://console.firebase.google.com/
2. اختر: etisak-784d6
3. اذهب: Firestore Database → Rules
4. استبدل القواعد بهذه:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

5. اضغط: Publish
6. امسح الـ Cache: Ctrl + Shift + R
7. سجل دخول
8. البيانات ستظهر! ✅
