🎯 الطريقة: رفع الملف مباشرة
═══════════════════════════════════════════════════════════════════


الخطوة 1: افتح Cloud Shell
───────────────────────────────────────────────────────────────────
1. اذهب إلى: https://console.cloud.google.com
2. ستجد في الأعلى أيقونة Terminal (>_)
3. اضغط عليها
4. سيفتح Cloud Shell في الأسفل

   ┌─────────────────────────────────────────────────────┐
   │  Google Cloud Console                    [>_]  👤  │
   │─────────────────────────────────────────────────────│
   │                                                     │
   │                                                     │
   │                                                     │
   └─────────────────────────────────────────────────────┘
   ┌─────────────────────────────────────────────────────┐
   │ Cloud Shell                              ⋮  ─  ✕   │
   │─────────────────────────────────────────────────────│
   │ user@cloudshell:~$                                  │
   └─────────────────────────────────────────────────────┘


الخطوة 2: رفع الملف
───────────────────────────────────────────────────────────────────
1. في Cloud Shell، اضغط على الثلاث نقاط (⋮) في الأعلى
2. اختر "Upload file"
3. اختر الملف من مشروعك:
   backend_v2/UPDATED_solver_service.py
4. اضغط "Upload"

   ┌─────────────────────────────────────────────────────┐
   │ Cloud Shell                              ⋮  ─  ✕   │
   │                                          │          │
   │                                    ┌─────┴────────┐ │
   │                                    │ Upload file  │ │
   │                                    │ Download file│ │
   │                                    │ Restart      │ │
   │                                    └──────────────┘ │
   └─────────────────────────────────────────────────────┘


الخطوة 3: نقل الملف للمكان الصحيح
───────────────────────────────────────────────────────────────────
انسخ والصق هذا الأمر:

mv UPDATED_solver_service.py ~/backend_v2/app/services/solver_service.py

اضغط Enter


الخطوة 4: النشر
───────────────────────────────────────────────────────────────────
انسخ والصق هذا الأمر:

cd ~/backend_v2 && gcloud run deploy schedule-solver --source . --region us-central1 --allow-unauthenticated --timeout 300 --memory 2Gi --cpu 2 --project etisak-784d6

اضغط Enter


الخطوة 5: انتظر
───────────────────────────────────────────────────────────────────
سترى:
- Building...
- Deploying...
- Done.
- Service URL: https://schedule-solver-979291699789.us-central1.run.app

هذا يعني النشر نجح! ✅


الخطوة 6: اختبر
───────────────────────────────────────────────────────────────────
1. اذهب إلى: https://etisak-784d6.web.app
2. جرب توليد الجدول
3. تحقق من أن كل يوم مختلف
