الخطوة 2: إصلاح صلاحيات Firebase (لجلب البيانات)
═══════════════════════════════════════════════════════════

1. افتح: https://console.firebase.google.com/
2. اختر مشروع: etisak-784d6
3. اذهب إلى: Firestore Database → Rules
4. استبدل القواعد بهذه:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

5. اضغط: Publish
6. انتظر: "Rules published successfully"
7. امسح الـ Cache: Ctrl + Shift + R
8. سجل دخول في التطبيق
9. البيانات ستظهر! ✅
