┌───────────────────────────────────────────────────────────────────┐
│ الخطوة 1: افتح Cloud Shell                                       │
└───────────────────────────────────────────────────────────────────┘

اذهب إلى هذا الرابط:
👉 https://console.cloud.google.com/?cloudshell=true

سيفتح لك Google Cloud Console مع Terminal في الأسفل


┌───────────────────────────────────────────────────────────────────┐
│ الخطوة 2: ارفع الملف                                             │
└───────────────────────────────────────────────────────────────────┘

في Cloud Shell:
1. اضغط على الثلاث نقاط (⋮) في الزاوية اليمنى العليا
2. اختر "Upload file"
3. اختر الملف: backend_v2/UPDATED_solver_service.py
4. اضغط "Upload"


┌───────────────────────────────────────────────────────────────────┐
│ الخطوة 3: انسخ والصق هذين الأمرين                               │
└───────────────────────────────────────────────────────────────────┘

الأمر الأول (انسخه والصقه واضغط Enter):
─────────────────────────────────────────────────────────────────
mv UPDATED_solver_service.py ~/backend_v2/app/services/solver_service.py
─────────────────────────────────────────────────────────────────

الأمر الثاني (انسخه والصقه واضغط Enter):
─────────────────────────────────────────────────────────────────
cd ~/backend_v2 && gcloud run deploy schedule-solver --source . --region us-central1 --allow-unauthenticated --timeout 300 --memory 2Gi --cpu 2 --project etisak-784d6
─────────────────────────────────────────────────────────────────


┌───────────────────────────────────────────────────────────────────┐
│ الخطوة 4: انتظر حتى ينتهي النشر                                 │
└───────────────────────────────────────────────────────────────────┘

سترى رسائل مثل:
- Building...
- Deploying...
- Done.
- Service URL: https://schedule-solver-979291699789.us-central1.run.app

عندما ترى "Done" و "Service URL" يعني النشر نجح! ✅
