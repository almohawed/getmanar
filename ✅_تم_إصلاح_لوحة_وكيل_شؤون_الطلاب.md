### 1. دالة `_buildStatCardsSection()` الجديدة
```dart
Widget _buildStatCardsSection() {
  final disciplineAsync = ref.watch(dailyDisciplineOverviewProvider);
  final behaviorAsync = ref.watch(behaviorStatsProvider);

  return disciplineAsync.when(
    data: (disciplineData) => behaviorAsync.when(
      data: (behaviorData) => عرض البطاقات,
      loading: () => Skeleton,
      error: (error, stack) => عرض خطأ,
    ),
    loading: () => Skeleton,
    error: (error, stack) => عرض خطأ,
  );
}
```

### 2. دالة `_buildStatCard()` المحسنة
```dart
Widget _buildStatCard(BuildContext context, String label, String value, Color color) {
  return Container(
    padding: EdgeInsets.symmetric(horizontal: 16.w, vertical: 12.h), // أصغر
    decoration: BoxDecoration(
      color: Colors.white,
      borderRadius: BorderRadius.circular(12.r),
      border: Border(
        right: BorderSide(color: color, width: 3.w), // خط ملون
      ),
    ),
    child: Row( // تصميم أفقي
      children: [
        Container(
          padding: EdgeInsets.all(10.w),
          decoration: BoxDecoration(
            color: color.withOpacity(0.1),
            borderRadius: BorderRadius.circular(10.r),
          ),
          child: Icon(_getIconForLabel(label), color: color, size: 22.sp),
        ),
        SizedBox(width: 12.w),
        Expanded(
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text(label, style: TextStyle(fontSize: 12.sp)),
              Text(value, style: TextStyle(fontSize: 20.sp, fontWeight: bold)),
            ],
          ),
        ),
      ],
    ),
  );
}
```

### 3. دالة `_getIconForLabel()` للأيقونات الديناميكية
```dart
IconData _getIconForLabel(String label) {
  if (label.contains('الطلاب')) return Icons.people;
  if (label.contains('الغياب')) return Icons.person_off;
  if (label.contains('التأخر')) return Icons.access_time;
  if (label.contains('المخالفات')) return Icons.warning;
  return Icons.info;
}
```

## 🔧 حل مشكلة الصلاحيات

إذا استمرت مشكلة الصلاحيات، تحقق من:

1. **Firestore Rules**:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /schools/{schoolId}/attendance/{document=**} {
      allow read: if request.auth != null && 
                     request.auth.token.schoolId == schoolId;
    }
    match /schools/{schoolId}/behavior/{document=**} {
      allow read: if request.auth != null && 
                     request.auth.token.schoolId == schoolId;
    }
  }
}
```

2. **User Claims**: تأكد من أن المستخدم لديه `schoolId` في الـ token

3. **Authentication**: تأكد من تسجيل الدخول بشكل صحيح
