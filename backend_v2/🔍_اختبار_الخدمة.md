# 🔍 اختبار الخدمة على Cloud Run

## جرب هذه الـ URLs بالترتيب:

### 1. Root endpoint
```
https://schedule-solver-979291699789.us-central1.run.app/
```

يجب أن ترى:
```json
{
  "message": "School Schedule Solver V2 is running",
  "health": "/api/v2/health",
  "precheck": "/api/v2/precheck",
  "generate": "/api/v2/generate"
}
```

### 2. Health endpoint
```
https://schedule-solver-979291699789.us-central1.run.app/api/v2/health
```

يجب أن ترى:
```json
{
  "status": "healthy",
  "name": "School Schedule Solver V2",
  "version": "2.0.0"
}
```

---

## إذا كلاهما يعطي "Not Found"

المشكلة قد تكون:
1. الخدمة لم تبدأ بعد (cold start)
2. مشكلة في الـ routing

جرب:
1. انتظر 30 ثانية وحاول مرة أخرى
2. افتح Cloud Run Console وتحقق من Logs
3. تحقق من أن الخدمة "serving 100% traffic"
