# 🧪 اختبار محلي أولاً - قبل النشر

## ⚠️ مهم جداً

**لا تنشر قبل الاختبار المحلي!**

---

## الخطوة 1: تثبيت المكتبات

```powershell
cd C:\Users\asus\my\almadrasah\backend_v2

pip install -r requirements.txt
```

انتظر حتى تكتمل التثبيت (قد يستغرق 2-3 دقائق لـ OR-Tools).

---

## الخطوة 2: تشغيل الخادم المحلي

```powershell
uvicorn app.main:app --reload --port 8080
```

يجب أن ترى:
```
INFO:     Uvicorn running on http://127.0.0.1:8080
INFO:     Application startup complete.
```

## الخطوة 3: اختبار Health Check

افتح المتصفح:
```
http://127.0.0.1:8080/api/v2/health
```

يجب أن ترى:
```json
{
  "status": "healthy",
  "name": "School Schedule Solver V2",
  "version": "2.0.0"
}
```

✅ إذا نجح، انتقل للخطوة التالية.
❌ إذا فشل، أرسل رسالة الخطأ.

## الخطوة 6: التحقق من الجدول

تحقق من:
1. ✅ عدد الحصص = 35 (5 أيام × 7 حصص)
2. ✅ لا تعارض للمعلم (نفس المعلم في نفس الوقت)
3. ✅ لا تكرار للمادة في نفس اليوم للفصل
4. ✅ كل معلم لديه العدد الصحيح من الحصص

## 📝 ملاحظة مهمة

النظام **لا يضمن 100% اكتمال بشكل مطلق**.

الصحيح:
- ✅ يضمن الالتزام بالقيود إذا كانت البيانات قابلة للجدولة
- ✅ يعيد `infeasible` إذا كانت البيانات غير قابلة للحل

- ❌ "ضمان 100% اكتمال" بشكل مطلق (يعتمد على البيانات)
