## 🚀 الخطوات الصحيحة الآن

### 1. تثبيت المكتبات

```powershell
cd C:\Users\asus\my\almadrasah\backend_v2

pip install -r requirements.txt
```

انتظر 2-3 دقائق (OR-Tools كبير).

---

### 2. تشغيل الخادم

```powershell
python -m uvicorn app.main:app --reload --port 8080
```

لاحظ: استخدمنا `python -m uvicorn` بدلاً من `uvicorn` مباشرة.

---

### 3. اختبار Health

افتح المتصفح:
```
http://127.0.0.1:8080/api/v2/health
```

يجب أن ترى:
```json
{
  "status": "healthy",
  "name": "School Schedule Solver V2",
  "version": "2.0.0"
}
```

---

### 4. اختبار Generate

في terminal جديد:

```powershell
cd C:\Users\asus\my\almadrasah\backend_v2

curl -X POST http://127.0.0.1:8080/api/v2/generate -H "Content-Type: application/json" -d @test_request.json
```

أو استخدم Postman:
- URL: `http://127.0.0.1:8080/api/v2/generate`
- Method: POST
- Body: Raw JSON من ملف `test_request.json`
