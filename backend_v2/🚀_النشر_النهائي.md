## 🔑 الخطوة 3: إضافة Firebase Credentials (اختياري)

بعد النشر، إذا أردت حفظ الجداول في Firebase:

1. افتح Cloud Run Console
2. اذهب إلى schedule-solver service
3. اضغط "Edit & Deploy New Revision"
4. اذهب إلى "Variables & Secrets"
5. أضف متغير بيئة:
   - Name: `FIREBASE_CREDENTIALS_JSON`
   - Value: محتوى ملف service account JSON في سطر واحد
