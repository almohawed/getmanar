└─────────────────────────────────────────────────────────┘

1. افتح Firebase Console:
   https://console.firebase.google.com/

2. اختر المشروع:
   etisak-784d6

3. اذهب إلى:
   Firestore Database → Rules

4. استبدل القواعد الموجودة بهذه:

   ┌─────────────────────────────────────────────────────┐
   │ rules_version = '2';                                │
   │ service cloud.firestore {                           │
   │   match /databases/{database}/documents {           │
   │     match /{document=**} {                          │
   │       allow read, write: if request.auth != null;   │
   │     }                                               │
   │   }                                                 │
   │ }                                                   │
   └─────────────────────────────────────────────────────┘

5. اضغط: Publish

6. انتظر رسالة التأكيد:
   "Rules published successfully"

7. ارجع للموقع وامسح الـ Cache:
   Ctrl + Shift + R

8. سجل دخول كوكيل شؤون طلاب

9. البيانات ستظهر الآن! ✅

المشكلة 1: التعديلات لا تظهر
-------------------------------
الحل:
- تأكد من استخدام نافذة Incognito
- أو امسح الـ Cache بالكامل:
  Ctrl + Shift + Delete → اختر "All time"

المشكلة 2: البيانات لا تُحمّل
-------------------------------
الحل:
1. افتح Developer Tools: F12
2. اذهب إلى Console
3. ابحث عن رسائل الخطأ:

   إذا رأيت "permission-denied":
   → تأكد من تحديث قواعد Firestore
   → تأكد من الضغط على Publish

   إذا رأيت "User not authenticated":
   → تأكد من تسجيل الدخول بشكل صحيح

المشكلة 3: البيانات تظهر "0" أو "..."
--------------------------------------
الحل:
1. تحقق من وجود بيانات في Firestore:
   - افتح Firebase Console
   - اذهب إلى Firestore Database
   - تحقق من وجود بيانات في:
     * Schools/{schoolId}/...
     * StudentAttendance
     * behavior_records

2. إذا لم توجد بيانات، أضف بيانات تجريبية
