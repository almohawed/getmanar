
## 📊 الإحصائيات المعروضة

### 1. الحصص المطلوبة (Required Lessons)
- **التعريف:** العدد المتوقع من الحصص التي يجب أن يدرسها المعلم
- **المصدر:** حقل `requiredLessons` في بيانات المعلم
- **المثال:** 24 حصة

### 2. الحصص المجدولة (Actual Lessons)
- **التعريف:** العدد الفعلي من الحصص المجدولة في الجدول
- **الحساب:** عدد الفترات التي تحتوي على حصة
- **المثال:** 24 حصة

### 3. الفترات الحرة (Free Periods)
- **التعريف:** أوقات لا يدرّس فيها المعلم
- **الحساب:** إجمالي الفترات - الحصص المجدولة
- **المثال:** 11 فترة

### 4. نسبة الإشغال (Completion %)
- **التعريف:** نسبة استخدام الفترات الزمنية
- **الحساب:** (الحصص المجدولة / إجمالي الفترات) × 100
- **المثال:** 68.6%

## 🔧 الاستخدام

### استخدام المكون في Flutter

```dart
import 'package:your_app/features/schedule/presentation/widgets/teacher_load_summary_widget.dart';

// في أي شاشة
TeacherLoadSummaryWidget(
  teacherName: 'أحمد محمد',
  requiredLessons: 24,
  actualLessons: 24,
  freePeriods: 11,
  totalPeriods: 35,
)
```

### استخدام الشاشة الكاملة

```dart
import 'package:your_app/features/schedule/presentation/teacher_schedule_with_summary_screen.dart';

// في التوجيه
GoRoute(
  path: '/teacher-schedule-summary',
  builder: (context, state) => TeacherScheduleWithSummaryScreen(
    teacherId: 'teacher123',
    schoolId: 'school456',
  ),
)
```

### تصدير PDF

```dart
import 'package:your_app/features/schedule/services/pdf_export_service.dart';

// سيتضمن الملخص تلقائياً
await PdfExportService.exportTeacherSchedules(schoolId);
```
