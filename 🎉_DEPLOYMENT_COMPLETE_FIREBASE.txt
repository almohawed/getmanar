🚀 الخطوات السريعة:
========================================

1. تثبيت Firebase CLI:
   npm install -g firebase-tools

2. تسجيل الدخول:
   firebase login

3. بناء التطبيق:
   flutter build web --release

4. تهيئة Firebase:
   firebase init hosting

5. النشر:
   firebase deploy --only hosting
