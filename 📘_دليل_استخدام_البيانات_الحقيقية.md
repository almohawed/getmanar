## 🚀 كيفية الاستخدام

### الطريقة 1: استخدام Providers مباشرة

#### في أي Widget:
```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../providers/academic_providers.dart';

class MyReportWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // جلب البيانات الحقيقية
    final performanceStatsAsync = ref.watch(performanceStatsProvider);
    
    return performanceStatsAsync.when(
      data: (stats) {
        // استخدام البيانات
        return Column(
          children: [
            Text('نسبة النجاح: ${stats.overallSuccessRate.toStringAsFixed(1)}%'),
            Text('نسبة التميز: ${stats.excellenceRate.toStringAsFixed(1)}%'),
            Text('نسبة التحسن: +${stats.improvementRate.toStringAsFixed(1)}%'),
          ],
        );
      },
      loading: () => CircularProgressIndicator(),
      error: (error, stack) => Text('خطأ في تحميل البيانات'),
    );
  }
}
```

### الطريقة 2: استخدام Services مباشرة

#### إذا كنت تريد التحكم الكامل:
```dart
import '../services/success_rates_service.dart';

class MyWidget extends StatefulWidget {
  @override
  _MyWidgetState createState() => _MyWidgetState();
}

class _MyWidgetState extends State<MyWidget> {
  final _service = SuccessRatesService();
  PerformanceStats? _stats;
  bool _loading = true;
  
  @override
  void initState() {
    super.initState();
    _loadData();
  }
  
  Future<void> _loadData() async {
    setState(() => _loading = true);
    try {
      final stats = await _service.calculatePerformanceStats(schoolId);
      setState(() {
        _stats = stats;
        _loading = false;
      });
    } catch (e) {
      setState(() => _loading = false);
    }
  }
  
  @override
  Widget build(BuildContext context) {
    if (_loading) return CircularProgressIndicator();
    if (_stats == null) return Text('لا توجد بيانات');
    
    return Text('نسبة النجاح: ${_stats!.overallSuccessRate}%');
  }
}
```

## 📊 البيانات المتاحة

### 1. PerformanceStats (نسب النجاح)
```dart
class PerformanceStats {
  final double overallSuccessRate;      // نسبة النجاح الإجمالية
  final double excellenceRate;          // نسبة التميز
  final double improvementRate;         // نسبة التحسن
  final Map<String, double> performanceLevels;  // توزيع المستويات
  final Map<String, double> successRatesByClass; // نسب النجاح حسب الفصول
  final int totalStudents;              // إجمالي الطلاب
  final int successfulStudents;         // الطلاب الناجحون
}

// مثال على الاستخدام:
stats.overallSuccessRate  // 87.5
stats.excellenceRate      // 42.3
stats.performanceLevels['excellent']  // 45.0
stats.performanceLevels['veryGood']   // 42.0
stats.successRatesByClass['الصف الأول']  // 85.0
```

### 2. GapStats (الفجوات التعليمية)
```dart
class GapStats {
  final int totalGaps;        // إجمالي الفجوات
  final int criticalGaps;     // الفجوات الحرجة
  final int resolvedGaps;     // الفجوات المعالجة
  final List<LearningGapInfo> gaps;  // قائمة الفجوات
}

class LearningGapInfo {
  final String subject;           // المادة
  final String className;         // اسم الفصل
  final String description;       // الوصف
  final int affectedStudents;     // عدد الطلاب المتأثرين
  final String priority;          // الأولوية (حرجة، متوسطة، منخفضة)
}

// مثال على الاستخدام:
gapStats.totalGaps       // 12
gapStats.criticalGaps    // 3
gapStats.gaps[0].subject // "الرياضيات"
gapStats.gaps[0].priority // "حرجة"
```

### 3. TeacherStats (أداء المعلمين)
```dart
class TeacherStats {
  final String teacherId;
  final String teacherName;
  final String teacherEmail;
  final double avgExcellence;    // متوسط تميز طلابه
  final int currentLoad;         // عدد الحصص الحالية
  final int maxLoad;             // الحد الأقصى للحصص
  
  double get loadPercentage;     // نسبة الحمل
}

// مثال على الاستخدام:
teacherStats[0].teacherName     // "أحمد محمد"
teacherStats[0].avgExcellence   // 85.5
teacherStats[0].currentLoad     // 18
teacherStats[0].maxLoad         // 24
teacherStats[0].loadPercentage  // 75.0
```

### مثال 1: عرض نسبة النجاح في Card

Consumer(

          );

## 🔄 التحديث التلقائي

البيانات تتحدث تلقائياً عند:
- تغيير المستخدم
- تغيير المدرسة
- إعادة بناء الـ Widget

```dart
// لإعادة تحميل البيانات يدوياً:
ref.invalidate(performanceStatsProvider);
ref.invalidate(gapStatsProvider);
ref.invalidate(teacherStatsProvider);
```
