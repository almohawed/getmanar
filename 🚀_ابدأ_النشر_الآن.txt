الخطوة 1: افتح Cloud Shell
────────────────────────────
https://console.cloud.google.com
(اضغط على أيقونة Terminal في الأعلى)


الخطوة 2: حدّث الملف
──────────────────────
cd ~/backend_v2/app/services
nano solver_service.py

ثم:
1. احذف كل المحتوى (Ctrl+K عدة مرات)
2. افتح الملف: backend_v2/UPDATED_solver_service.py
3. انسخ كل المحتوى (Ctrl+A ثم Ctrl+C)
4. ارجع لـ Cloud Shell والصق (زر الماوس الأيمن)
5. احفظ: Ctrl+O ثم Enter
6. اخرج: Ctrl+X


الخطوة 3: انشر
───────────────
cd ~/backend_v2

gcloud run deploy schedule-solver --source . --region us-central1 --allow-unauthenticated --timeout 300 --memory 2Gi --cpu 2 --project etisak-784d6
